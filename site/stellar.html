Data and validation

The target was GALAXY, QSO (quasar) or STAR, using sky coordinates, brightness in five bands, redshift and two categorical fields. Balanced accuracy gives each class equal weight.

Validation split the 577,347 rows into five folds with similar class proportions. Each row was predicted by a model trained on the other folds: an out-of-fold prediction. Comparisons reused these splits; learned feature transforms were fitted only on training rows.

Revising LightGBM supplied part of the improvement; combining models added a smaller gain. Threshold calibration slightly reduced the score.

Feature and model comparisons

Recorded 8 June 2026. Early screens used stratified subsamples, with score changes measured against a baseline on the same sample. The initial baseline and final stack used the full training set.

The best feature change was +0.00018. Later experiments tested different model families and ways to combine their predictions.
